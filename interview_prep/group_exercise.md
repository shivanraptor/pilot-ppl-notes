# Group Exercise

**Navigation:** [Interview hub](index.md) | [Home](../index.md)

Evaluates **CRM**: communication, listening, leadership without aggression, and **safety leadership** — not flying skill.

---

## Setup (typical)

| Item | Detail |
| --- | --- |
| Group size | ~6–12 candidates |
| Assessors | 2–3 (HR + pilots), observing only |
| Discussion | ~15–30 minutes |
| Presentation | ~5 minutes group summary |

---

## Scenario types

| Type | Task | CRM focus |
| --- | --- | --- |
| **Survival ranking** | Crash in desert/jungle; rank 15 items → top 5 | Justify priorities; include quiet members |
| **Resource allocation** | Limited budget; choose between projects | Safety vs commercial trade-offs |
| **Scheduling / disruption** | Weather; prioritise flights or cargo | Time management; consensus |
| **Flight package / dispatch** | Brief + decision from route, weather, fuel package | See [example PDF](docs/flight_package.pdf) and workflow below |

## Flight package group exercise

### Materials on this site

- **[Example flight package (PDF)](docs/flight_package.pdf)** — practice briefing format
- **[SimBrief](https://www.simbrief.com)** — generate a realistic package for group practice ([resources](../useful_resources/resources.md))

### Suggested group workflow

| Phase | Time | Actions |
| --- | --- | --- |
| Individual read | 5 min | Note threats: weather, fuel, alternates, duty limits |
| Round-robin | 2 min each | Each candidate states top risk + recommendation |
| Debate | 10–15 min | Agree go / delay / divert; document **why** |
| Presentation | 5 min | Spokesperson: situation, decision, risks, contingency |

### Roles to volunteer for

| Role | Shows |
| --- | --- |
| **Timekeeper** | SA, mission focus |
| **Scribe** | Structured thinking |
| **Spokesperson** | Clear summary (only if comfortable) |

### Safety leadership (2025–2026 emphasis)

If trade-off is **time/money vs safety**, choose the **safest defensible** option and acknowledge commercial impact.

Example phrase: “I recommend we delay departure until the thunderstorm line passes — the cost of a late departure is lower than the risk of a windshear encounter on takeoff.”

---

## Scoring behaviours

| Positive | Negative |
| --- | --- |
| Use names; invite quiet members | Interrupting |
| Build on others’ ideas | Dominating airtime |
| Track time | Ignoring group consensus after debate |
| Support final group position | Stubborn refusal after vote |

---

## Golden rules

| Do | Don't |
| --- | --- |
| Volunteer timekeeper or scribe | Interrupt |
| Ask quiet members for input | Talk 80% of the time |
| Refocus off-topic debate | Undermine group decision in presentation |
| Advocate safety with reasoning | Ignore assessor instructions |

---

## Practice plan

| Week | Activity |
| --- | --- |
| 1 | Solo: rank survival list in 10 min; write rationale |
| 2 | Pair: debate one resource-allocation case |
| 3 | Group of 4+: flight package PDF + 20 min decision + 5 min brief |
| 4 | Full simulation with timer and assigned spokesperson |
