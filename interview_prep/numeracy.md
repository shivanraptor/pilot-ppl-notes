# Aptitude Numeracy Worksheet

**Navigation:** [Interview hub](index.md) | [Aptitude tests](aptitude_tests.md) | [Home](../index.md)

Practice for the **applied numeracy** module in Cathay’s computer-based battery. Work **without a calculator** first; then check answers. Target: each question in under 60 seconds.

---

## Formulas to memorise

| Topic | Formula |
| --- | --- |
| Distance | Distance (NM) = GS (kt) × Time (hr) |
| Time | Time (hr) = Distance (NM) ÷ GS (kt) |
| Fuel used | Fuel = Flow (kg/hr or L/hr) × Time (hr) |
| Percentage | Part ÷ Whole × 100 |
| Average speed | Total distance ÷ Total time |

## Set A — Speed, distance, time

| # | Question | Your answer |
| --- | --- | --- |
| A1 | GS 120 kt. How far in 45 minutes? | |
| A2 | 90 NM at GS 180 kt. Time in minutes? | |
| A3 | 220 NM in 1 hr 50 min. GS in kt? | |
| A4 | Climb 3,000 ft in 6 min. Average rate of climb (ft/min)? | |
| A5 | Fuel flow 240 kg/hr for 2 hr 15 min. Fuel used (kg)? | |

<details>
<summary>Answers — Set A</summary>

| # | Answer | Working |
| --- | --- | --- |
| A1 | **90 NM** | 120 × 0.75 hr |
| A2 | **30 min** | 90 ÷ 180 = 0.5 hr |
| A3 | **120 kt** | 220 ÷ (11/6) ≈ 120 |
| A4 | **500 fpm** | 3000 ÷ 6 |
| A5 | **540 kg** | 240 × 2.25 |

</details>
